Two open-source ecommerce projects

Neither is a component of the other, and neither is a component of this website. They are two repositories, maintained separately, that happen to fit together well.

Use them independently. Or use them together.

GoCommerce and Svelte Commerce are standalone projects. Use either one with your existing stack, or combine them for a complete Go + Svelte ecommerce architecture.

GoCommerce on its own

A documented JSON API and an admin panel, serving any storefront you already have — Next.js, Nuxt, Astro, a native app, or your own Svelte build.

Svelte Commerce on its own

A storefront over a backend you already run. It is headless today across Medusa, Shopify, Saleor, Vendure, WooCommerce and Litekart.

Both together

The Go + Svelte pairing this site exists to describe: SvelteKit in front, Go behind, PostgreSQL underneath, all of it yours to host.

GoCommerce ↔ Svelte Commerce

Connector in development

Svelte Commerce speaks to several commerce backends today. GoCommerce is not one of them yet: the connector that maps the GoCommerce API onto the storefront’s data layer is being written and is not published.

Until it lands, pairing the two means writing that client yourself against the documented GoCommerce API. That is the honest state of it, and it is the single most useful thing anybody could help with.

How a request flows

Nothing here proxies for something else. The storefront talks to the backend over ordinary HTTP, the backend owns the commerce rules and the database, and everything optional sits beside that line rather than on it.

How the two projects relate

Direct answers, including the unflattering ones. If a question here has a bad answer, that is the answer.

What is GoCommerce?

GoCommerce is an open-source ecommerce backend and admin application built with Go. It provides commerce APIs, PostgreSQL persistence and an admin interface, and it is self-hosted under an MIT licence.

What is Svelte Commerce?

Svelte Commerce is an open-source ecommerce storefront built with Svelte. It is a headless storefront, which means it renders the shopping experience and calls a separate commerce backend for the data.

What is kitcommerce.store?

kitcommerce.store is the website that presents GoCommerce and Svelte Commerce, two open-source ecommerce projects. It is not itself a product, a platform or a framework, and there is nothing called KitCommerce to install.

Do GoCommerce and Svelte Commerce require each other?

No. Both projects can be used independently, but they can also be combined to build a complete ecommerce stack. GoCommerce runs with no Svelte storefront in front of it, and Svelte Commerce runs against backends that are not GoCommerce.

Can Svelte Commerce work with another ecommerce backend?

Yes. Svelte Commerce is a headless storefront capable of integrating with compatible commerce backends. It supports Medusa, Shopify, Saleor, Vendure, WooCommerce and Litekart today.

Can GoCommerce work with another frontend?

Yes. GoCommerce exposes commerce backend functionality that can be consumed by compatible storefronts and applications. It serves 342 documented operations over REST, published as OpenAPI, so any framework that can call HTTP can drive it.

Can I run the two together today?

Not without writing the glue yourself. The connector that maps the GoCommerce API onto the Svelte Commerce data layer is in development and unpublished. Until it ships, pairing them means writing that client against the documented GoCommerce API.

Are both projects open source, and is there a paid tier?

Both are MIT licensed. There is no hosted offering, no paid tier, no enterprise edition and nothing to buy. Rename either one, restyle it, cut what you do not need, and ship it under your own name.

Are they production-ready?

They differ. Svelte Commerce has been public for years and runs production stores. GoCommerce is pre-1.0, its API may change before 1.0, it carries 1,036 tests and a documented contract for every route, and no store we know of is running it in production yet.
