03 — THE CUSTOMER SIDE

Go behind it.
Svelte in front.

The engine speaks JSON over HTTP, so the shop front is your choice — SvelteKit, Next, Astro, an app, or a till in a physical shop. Svelte Commerce is a ready-made SvelteKit storefront you can start from.

  • 01Any framework that can call an HTTP API
  • 02Build the journey from discovery to checkout
  • 03Connect through a shared commerce API
Explore Svelte Commerce ↗

Svelte Commerce ships connectors for several backends; a GoCommerce connector is not published yet, so wiring it to this engine is work you would be doing yourself today. The API reference at /docs is the contract.
